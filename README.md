# Cases

Estudos de caso de engenharia analítica: como o dado é coletado, tratado e
entregue. Cada linha abaixo é um case, seja uma pasta deste repositório ou um
repositório próprio quando o projeto é maior.

| Case | Tema |
|---|---|
| [`ga4-extracao/`](ga4-extracao/) | As 3 formas de extrair os dados do Google Analytics 4: Data API, export nativo e Data Transfer Service. Os três estão documentados; o Caminho 1 vem com código pronto, os Caminhos 2 e 3 com passo a passo e SQL de exemplo. |
| [`arquitetou`](https://github.com/Lokkoman/arquitetou) | Agregador de vagas com coleta multi-fonte: via API onde a fonte oferece (Gupy, LinkedIn via Bright Data) e scraping HTML no resto. Classificação por IA com o Gemini (relevância, senioridade, modalidade, ferramentas, faixa salarial, resumo). Site estático no GitHub Pages. Repositório próprio. |

Mais cases entram como novas pastas ou links para repositórios próprios.
